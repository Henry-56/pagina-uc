# Semana de Ingeniería 2026 - Universidad Continental (pagina-uc)

Este es un proyecto web desarrollado en [Next.js](https://nextjs.org/) para el cronograma de la Semana de Ingeniería 2026 de la Universidad Continental.

## Características:
- Diseño corporativo UX/UI premium inspirado en `ucontinental.edu.pe`
- Colores institucionales: Azul (`#023F88`) y Arena (`#F6DDBB`)
- Animaciones glassmorphism suaves e iconos de Lucide-React.
- Cronograma dinámico con color coding según facultades de Ingeniería.

## Cómo ejecutar localmente:
```bash
npm install
npm run dev
```
Luego abre [http://localhost:3000](http://localhost:3000) en tu navegador.
